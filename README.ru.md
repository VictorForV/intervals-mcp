# Intervals MCP

[English version](README.md)

Самостоятельно размещаемый read-only MCP-сервер, который даёт ИИ-ассистентам
доступ к тренировочным данным спортсмена из
[Intervals.icu](https://intervals.icu/).

Подключите спортивные часы, велокомпьютер, тренажёр, Strava или другой
поддерживаемый источник к Intervals.icu. После этого Intervals MCP сможет
передавать нормализованные данные в ChatGPT, Claude, Claude Code, Cursor, VS Code
и другие MCP-клиенты. Актуальный список интеграций смотрите на
[Intervals.icu](https://intervals.icu/) — со временем он меняется.

Сервер выполняет только `GET`-запросы и не может создавать, изменять или удалять
данные в аккаунте Intervals.icu.

## Какие данные доступны

- Профиль, часовой пояс, спортивные настройки и тренировочные зоны.
- Тренировки, подробности, круги, интервалы и прореженные потоки датчиков.
- Самочувствие, форма, усталость, HRV, сон, настроение и вес при их наличии.
- Оценка готовности к тренировкам в стиле тренера: форма (TSB) по категориям,
  оценка темпа набора нагрузки и отклонение свежего HRV от базового уровня.
- PNG-график CTL/ATL/TSB по времени — когда форма кривой говорит больше, чем
  голые цифры.
- События, лучшие результаты, экипировка и библиотека тренировок.
- Дополнительные `GET`-эндпоинты Intervals.icu v1 через read-only инструмент.

Большие ответы сокращаются перед передачей модели: пустые поля удаляются, потоки
прореживаются, а статистика рассчитывается по полной серии.

## Быстрый старт

Потребуется VPS с Ubuntu или Debian и публичным доменом. Направьте DNS-запись
домена на сервер и откройте TCP-порты 80 и 443. Установщик сам
добавит Docker, Compose, Git и uv, если их нет:

```bash
curl -fsSL https://raw.githubusercontent.com/VictorForV/intervals-mcp/master/install.sh | sudo bash
```

Если вы не хотите передавать удалённый скрипт в root-shell, снача изучите
[`install.sh`](install.sh). Также можно вручную установить зависимости,
клонировать репозиторий и запустить `./manage.sh`.

Выберите **Initial setup**. Менеджер запросит публичный домен, короткое имя
спортсмена, athlete ID и API key из Intervals.icu. ID и ключ находятся в разделе
**Settings → Developer Settings**. Ввод API key будет скрыт.

Менеджер создаст защищённые конфиги, сгенерирует случайный секрет для URL,
запустит сервис и покажет ссылки. Повторно запускайте `./manage.sh`, чтобы
добавлять, просматривать, изменять и удалять спортсменов, перевыпускать ссылки,
обновлять сервис и смотреть статус или логи.

## Подключение ИИ-клиента

Для каждого спортсмена создаются две секретные ссылки:

```text
https://mcp.example.com/<secret>/mcp  # рекомендуемый Streamable HTTP
https://mcp.example.com/<secret>/sse  # совместимость со старым SSE
```

Полная ссылка равнозначна паролю и открывает чтение данных этого спортсмена.

### Claude и Claude Desktop

Откройте **Settings → Connectors → Add custom connector** и добавьте `/mcp` URL.
Доступность и права зависят от тарифа. Проверяйте актуальную
[инструкцию Anthropic](https://support.anthropic.com/en/articles/11175166-about-custom-integrations-using-remote-mcp).

### Claude Code

Менеджер напечатает готовую команду:

```bash
claude mcp add --transport http intervals-alex https://mcp.example.com/<secret>/mcp
```

### ChatGPT

Добавьте сервер как custom app/connector и используйте URL, который принимает
ваш текущий workspace. Интерфейс, доступность и требования к правам зависят от
тарифа и могут меняться. Сверяйтесь с актуальной
[документацией OpenAI](https://help.openai.com/en/articles/11487775-connectors-in-chatgpt).
Менеджер показывает оба URL для совместимости.

### Другие клиенты

Для Streamable HTTP используйте `/mcp`, для старых SSE-клиентов — `/sse`. Не
сохраняйте секретную ссылку в общедоступных конфигурациях.

## Управление

Рекомендуемый интерфейс — интерактивная панель:

```bash
./manage.sh
```

Для автоматизации доступны подкоманды:

```bash
uv run intervals-mcp-admin add
uv run intervals-mcp-admin list
uv run intervals-mcp-admin show alex
uv run intervals-mcp-admin edit alex
uv run intervals-mcp-admin rotate alex
uv run intervals-mcp-admin remove alex
```

Не передавайте ключ через `--api-key` в интерактивной оболочке: аргумент может
попасть в историю или список процессов. Без флага используется скрытый ввод.

## Безопасность

- В Intervals.icu отправляются только `GET`-запросы.
- У каждого спортсмена отдельный API-клиент и случайный URL token.
- `.env` и `users.toml` исключены из Git и имеют права `0600`.
- Ключи и URL token не попадают в access logs.
- Публичный сервис работает через HTTPS с Caddy.
- `users.toml` подключается к контейнеру только для чтения.

Секрет в URL работает как bearer-доступ: получивший ссылку сможет читать данные.
При утечке перевыпустите её через `./manage.sh`. Порядок сообщения об
уязвимостях описан в [SECURITY.md](SECURITY.md).

## Разработка

```bash
uv sync
uv run pytest
```

Тесты используют полностью синтетические fixtures в форме ответов API и не
обращаются к сети. Их можно пересоздать командой
`uv run python scripts/generate_fixtures.py`.

Правила участия находятся в [CONTRIBUTING.md](CONTRIBUTING.md).
